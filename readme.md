# reticle

lightweight crosshair overlay for windows. sits quietly in the tray and draws a small reticle in the center of the screen.

## tray menu

- **size:** tiny / small / medium
- **shape:** dot / cross / ring / square
- **color:** white / red / blue / green
- **exit**

## download

go to [releases page](https://github.com/luzdivina-s7n/ReTicle/releases/)

## performance

- memory: ~2 mb
- cpu: 0% idle

## build

requires windows and .net framework 4.0+.

```
build.bat
```

produces `rtc.exe`.

## run

requires windows and .net framework 4.0+. run `rtc.exe`.
